# OURSPACE V2.3 — PRODUCTION DATA CLEANUP & SAFETY PROTOCOL

## 1. Overview & Data Safety Policy
To ensure OURSPACE delivers a genuine, pristine experience for couples, all hardcoded placeholder data, dummy Unsplash photos, mock documents, fake message threads, and artificial events have been systematically eliminated.

### Core Safety Guarantee
> **NEVER DELETE ACTUAL USER CONTENT.**
Cleanup operations strictly differentiate between seeded demonstration fixtures and authentic couple content. Under no circumstance are user-uploaded photographs, real chat messages, or active private spaces touched.

---

## 2. Distinguishing Demo Data from User Data

| Characteristic | Demo / Sample Content | Authentic User Content |
|---|---|---|
| **Storage Paths** | `mock/*`, `unsplash.com`, `sample/*` | Real Firebase Storage URIs or Base64 data URLs |
| **Space IDs** | `11111111-1111-1111-1111-111111111111` | UUID v4 generated by Cloud Firestore |
| **User IDs** | `00000000-0000-0000-0000-000000000001/2` | Real Firebase Auth UIDs |
| **Document Names** | `dummy.pdf`, `ForBiggerBlazes.mp4` | Actual client device file names |
| **Dates** | Static hardcoded future dates | Real `serverTimestamp()` / ISO-8601 timestamps |

---

## 3. Cleanup Tool Usage: `scripts/cleanup-demo-data.mjs`
The cleanup engine is equipped with safety mechanisms:

### 1. Default Dry-Run Mode (Safe Simulation)
```bash
node scripts/cleanup-demo-data.mjs --dry-run
```
Scans records, identifies fixtures matching demo patterns, and prints an audit report without altering or deleting any records.

### 2. Live Production Execution with Mandatory Backup
```bash
node scripts/cleanup-demo-data.mjs --confirm-production --backup
```
- First exports a timestamped JSON backup (`backup_pre_cleanup_<timestamp>.json`).
- Purges only confirmed demo items.
- Outputs a detailed audit summary showing records purged vs. user records protected.

---

## 4. Elegant Empty State Standard
When a new couple registers or an active space has no items in a category:
- Screens do **not** fall back to dummy mock cards.
- Screens render **purpose-built empty states** with soft romantic illustrations, clear headers, and an actionable primary button (e.g., *"Upload Your First Photo"*, *"Create Your First Album"*, *"Write Your First Note"*).
